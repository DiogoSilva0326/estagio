# Wishlist e Favoritos

## Visao Geral
- Utilizador adiciona/remover cursos da wishlist.
- Utilizador adiciona/remover professores como favoritos.

## Diagrama de Sequencia
- Ficheiro: `DiagramasSequencia/Wishlist.md`

## APIs Envolvidas
- POST `/api/wishlist/items` – adicionar curso
- DELETE `/api/wishlist/items/{id}` – remover curso
- POST `/api/favorites/items` – favoritar professor
- DELETE `/api/favorites/items/{id}` – remover favorito

## Tabelas Necessarias
- `wishlists`, `wishlist_items` (cursos)
- `favorites`, `favorite_items` (professores)
- `courses`, `professors`, `users`

## SQL (Postgres) – Tabelas
> Definicoes completas em `sql/postgres/schema_all.sql`. Extractos principais:

```sql
CREATE TABLE IF NOT EXISTS wishlists (
  id_wishlist INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  id_user INTEGER NOT NULL REFERENCES users(id_user) ON DELETE CASCADE,
  created_at TIMESTAMP DEFAULT now()
);

CREATE TABLE IF NOT EXISTS wishlist_items (
  id_wishlist_item INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  id_wishlist INTEGER NOT NULL REFERENCES wishlists(id_wishlist) ON DELETE CASCADE,
  course_id INTEGER REFERENCES courses(id_course) ON DELETE SET NULL,
  added_at TIMESTAMP DEFAULT now()
);

CREATE TABLE IF NOT EXISTS favorites (
  id_favorite INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  id_user INTEGER NOT NULL REFERENCES users(id_user) ON DELETE CASCADE,
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);

CREATE TABLE IF NOT EXISTS favorite_items (
  id_favorite_item INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  id_favorite INTEGER NOT NULL REFERENCES favorites(id_favorite) ON DELETE CASCADE,
  id_professor INTEGER NOT NULL REFERENCES professors(id_professor) ON DELETE CASCADE,
  added_at TIMESTAMP DEFAULT now(),
  UNIQUE(id_favorite, id_professor)
);
```

## Regras de Negocio
- Um mesmo professor nao deve ser duplicado em `favorite_items` por `id_favorite`.
- Um mesmo curso nao deve ser duplicado em `wishlist_items` por `id_wishlist`.
