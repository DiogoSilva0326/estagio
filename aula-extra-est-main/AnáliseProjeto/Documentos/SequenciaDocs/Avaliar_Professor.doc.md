# Avaliar Professor

## Visao Geral
- O aluno submete avaliacao e comentario para um professor apos uma aula.

## Diagrama de Sequencia
- Ficheiro: `DiagramasSequencia/Avaliar_Professor.md`

## APIs Envolvidas
- POST `/api/professors/{id}/feedback`
- GET `/api/professors/{id}/feedback`

## Tabelas Necessarias
- `professor_feedback`, `professors`, `users`

## SQL (Postgres) – Tabelas
> Definicoes completas em `sql/postgres/schema_all.sql`. Extracto principal:

```sql
CREATE TABLE IF NOT EXISTS professor_feedback (
  id_professor_feedback INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  id_professor INTEGER NOT NULL REFERENCES professors(id_professor),
  id_user INTEGER NOT NULL REFERENCES users(id_user),
  is_valid BOOLEAN DEFAULT true,
  rating INTEGER,
  comments TEXT,
  created_at TIMESTAMP DEFAULT now()
);
```

## Validacoes e Regras
- `rating` dentro do intervalo permitido (ex.: 1..5).
- O utilizador deve ter participado numa aula para avaliar (validacao aplicacional).
